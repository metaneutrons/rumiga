# M0-012: Versioned Engineering Governance

- Status: Unreleased
- Change type: Changed
- Task: M0-012
- Audience: Contributors and maintainers

## Summary

Rumiga now provides versioned contribution, review, pull-request, issue,
release-note, ADR, and change-record contracts. A Rust-owned quality gate checks
their structure and publishes checksummed governance evidence in CI.

## User And Operator Impact

None. Emulator runtime behavior and media formats are unchanged.

## Compatibility And Migration

Existing code and configurations need no migration. New material changes must
link a stable task and a machine-readable record before promotion.

## Verification

`cargo +1.97.1 xtask ci --gate governance` validates all contracts, the M0-012
traceability example, exact evidence checksums, and CI topology.

## Known Limitations

This baseline does not define release versioning, release branches, changelog
assembly, or long-term support policy; those remain M10-001.
