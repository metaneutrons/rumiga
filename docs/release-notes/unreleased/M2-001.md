# M2-001: reTerminal D1001 Hardware Manifest

- Status: Unreleased
- Change type: Added
- Task: M2-001
- Audience: Embedded integrators and maintainers

## Summary

The target board is documented: revision identity, BSP commit, silicon inventory, and
every connector with its designator and manufacturer part, each value naming its source.

## User And Operator Impact

Nothing changes for a user. M2's bring-up tasks now have part numbers, connector
designators, and bus addresses to work from instead of a product page.

Three existing architecture claims gained a source, and one turned out weaker than it
read. The panel, the audio codec, and the wireless coprocessor are confirmed. The 32 MiB
PSRAM figure that the memory budget rests on is a wiki claim about the `ESP32-P4NRW32`
variant; the schematic symbol carries only the family name, and the manifest says so.

## Compatibility And Migration

`docs/hardware/` is new and holds one manifest per board. No code or configuration
changes.

Derived values stay where they already live: flash layout in `firmware/partitions.csv`,
memory budgets in `ARCHITECTURE.md`, toolchain pins in `toolchain/manifest.toml`.

## Verification

The schematic revision, its date, the sheet structure, the parts, and all eleven
connectors were read from the V01 schematic PDF, whose SHA-256 is recorded in the
manifest. The BSP commit was read through the GitHub API.

Reading the schematic rather than the specification table is what produced the connector
designators, which are the part M2 actually needs and which no vendor overview page
lists.

## Known Limitations

Nothing is verified against a physical board. Every value comes from a document; no unit
has been powered and no connector probed.

Two findings are recorded as unresolved rather than answered. The wiki advertises
expansion interfaces that the V01 schematic does not show as a connector: its only
2.54 mm header carries the ESP32-C6's programming signals, and the `EXP_GPO` nets belong
to an I/O expander driving on-board functions. And the schematic carries a `Wio-LR1121`
sub-GHz module with an SMA connector that the wiki never mentions, with no population
marking either way.

Board and enclosure dimensions are not published in text. The 3D model would answer this
and was not opened.

Four vendor documents were not read: the SCH and PCB source archive, the SoC and
peripheral datasheets, and the 3D model.
