# M0-016: Repository-Standard Doctor Remediation

- Status: Unreleased
- Change type: Changed
- Task: M0-016
- Audience: Contributors and maintainers

## Summary

The repository now follows the repo-standard Doctor baseline for the local and
hosted engineering workflow: Node.js 24.20.0 LTS, pnpm 12.3.4, a frozen web
lockfile, strict web checks, coverage checks, Lefthook hooks, and security
policy documentation are versioned and enforced.

Safe Class A GitHub settings were applied. The branch-protection ruleset
migration is deliberately deferred while foreign Dependabot pull requests are
open. No release, tag, publication, release environment, or release credential
was created or changed.

## User And Operator Impact

Contributors install the web dependencies with `pnpm --dir web install
--frozen-lockfile`; the package prepare hook installs Lefthook. Web lint,
typechecking, tests, and Rust/web coverage are part of the quality baseline.

## Compatibility And Migration

Remove the old web `package-lock.json` from local checkouts and run the frozen
pnpm install. The runtime baseline is Node.js `24.20.0` and pnpm `12.3.4`.

## Verification

- `pnpm --dir web install --frozen-lockfile --ignore-scripts`
- `pnpm --dir web lint`
- `pnpm --dir web typecheck`
- `pnpm --dir web test --run`
- `pnpm --dir web build`
- `cargo +1.97.1 nextest run --workspace --locked`

- repo-standard Doctor gate and GitHub settings read-back

## Known Limitations

The standard GitHub ruleset transition remains blocked by the open foreign pull
requests. Existing classic protection on `main` remains active. Release
planning is explicitly deferred.
